Saya adalah seorang **Web & Mobile Developer** dan **Tech Innovator** yang berfokus pada pengembangan antarmuka pengguna yang interaktif, responsif, dan berkinerja tinggi. Memiliki passion mendalam dalam mentransformasikan ide serta rancangan arsitektur kompleks menjadi aplikasi web dan mobile yang intuitif dengan seamless user experience.

Saat ini mengemban amanah sebagai **Ketua Himpunan Mahasiswa Teknologi Informasi dan Komputer (HIMATIKOM)** di **Politeknik Negeri Subang** periode 2024–2025, setelah sebelumnya berkontribusi aktif sebagai **Anggota Departemen Pengembangan Sumber Daya Anggota (PSDA) HIMATIKOM** (2023–2024). Terbiasa memimpin tim, mengelola proyek kolaboratif, serta mengeksplorasi ekosistem teknologi modern mulai dari Next.js, TypeScript, Laravel, hingga native scripting PowerShell dan AI workflows.

**🚧 Proyek Pilihan (What I'm building)**

- 🎧 **[BINAR (Bina Netra)](https://github.com/23Barajapu/Binar)**: Platform literasi buku suara & ujian mandiri berbasis aturan untuk siswa tunanetra (SLB Negeri Subang). Dibangun dengan arsitektur **Rust Modular Monolith** di backend dan **Flutter Zero-Visual Gesture UI** di mobile.
- 🧹 **[cleaner-windows](https://github.com/23Barajapu/cleaner-windows)**: Windows Deep Uninstaller & Root Cleaner native TUI berbasis PowerShell & Win32 API.
- 💳 **[money-management](https://github.com/23Barajapu/money-management)**: Personal finance & expense tracker interaktif dengan visualisasi analytics berbasis React, TypeScript, Supabase, dan Expo.
- 🌾 **SIMPADA**: Sistem Informasi Pertanian & Monitoring Lahan Daun Padi / Tembakau dengan integrasi WebGIS menggunakan PHP Laravel dan MySQL.
- 🚗 **Biro Jasa Mahkota**: Enterprise management system untuk pengurusan dokumen administrasi kendaraan bermotor (STNK, BPKB, Balik Nama, dan Mutasi).

**🧠 Keahlian & Ketertarikan (What I'm into)**

- 🦀 **Systems & Inklusi Digital**: Pemrograman performa tinggi dan handal menggunakan **Rust** (Modular Monolith, Rule Engines, Actix/Axum) dan klien mobile **Flutter** berbasis zero-visual canvas untuk aksesibilitas siswa tunanetra.
- ⚡ **Modern Frontend**: React, Next.js 13+, TypeScript, Tailwind CSS, Three.js & Framer Motion untuk antarmuka berkecepatan tinggi.
- 🛠️ **Fullstack & Backend**: PHP (Laravel), Python (Django), PostgreSQL, Redis, MySQL, Supabase, RESTful API & JWT authentication.
- 🤖 **AI-Driven Workflows**: Pemanfaatan AI agents, Google Antigravity, Speech-to-Text (STT), Text-to-Speech (TTS), dan OCR engine (Tesseract).
- 🖥️ **System Utilities & Shell**: PowerShell automation, native Windows optimization, dan developer tooling.
- 👥 **Leadership & Community**: Manajemen organisasi mahasiswa (Ketua HIMATIKOM & mantan Anggota Dept. PSDA), mentoring teknis, dan public speaking di bidang teknologi informasi.

**⚡ Quick Facts**

- 📍 Berdomisili di **Subang, Jawa Barat, Indonesia 🇮🇩**
- 🎓 Mahasiswa Teknologi Informasi & **Ketua HIMATIKOM Politeknik Negeri Subang (2024 - 2025)**
- ☕ Didorong oleh rasa ingin tahu tinggi, clean code, lo-fi beats, dan secangkir kopi
- 💬 Terbuka untuk diskusi seputar Web/Mobile Dev, Laravel, React, TypeScript, UI/UX, atau organisasi
- 🤝 Siap berkolaborasi untuk proyek open source, software engineering, maupun inovasi digital
